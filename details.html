Data sources

  • CO2 Emission by Vehicles (Kaggle), the main dataset: 7,385 rated vehicles from the Government of Canada, of which the BMW and Mercedes-Benz rows are used here.
  • Fuel consumption ratings (Government of Canada), the original source of the main dataset.
  • 2024_Cars_Aggregated.csv, the European real-world (OBFCM) fleet file used in the first version of this project.
